# Security Policy

## Supported version

The latest revision on the `main` branch receives security fixes during active development.

## Reporting a vulnerability

Use the repository's private vulnerability-reporting channel when available. Do not attach private images,
EXIF records, GPS coordinates, filenames, or other sensitive samples to a public issue. A synthetic fixture or
minimal reproduction is preferred.

Include the affected route, browser version, operating system, expected behavior, observed behavior, and a
minimal reproduction. Do not test against images or devices you do not own or have permission to use.

## Security boundary

Pixavelo is a static browser application. The project does not provide accounts, remote image storage, or an
image-processing API. A vulnerability report should not assume those systems exist.
